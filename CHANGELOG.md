# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/), and this project adheres to [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-03-20

### Added

- 31 design style specifications covering tokens, components, layout, motion, and accessibility
- 31 token cards for fast style selection and blend compatibility checking
- Style conflict matrix with family-level rules, pairwise conflicts, bridge styles, and blend recipes
- 5 task archetypes: Marketing, Application UI, Dashboard, Component Library, Editorial
- 7 Flow types: Cascading, Radial, Grid-Locked, Orbital, Rhythmic, Convergent, Kinetic
- 4-phase agent protocol: Style Selection, Context Assessment, Blocking Task List, QA Watcher
- Automated QA lint script with 9 checks (token adherence, accessibility, completeness)
- Universal installer with auto-detection for Amp CLI, Claude Code, Gemini CLI, and OpenCode
- Sync status tool for detecting drift across installations
- Style normalizer script for consistent formatting
- npm package with CLI (`ui-architect-skill` binary)
- Claude Code plugin structure (`.claude-plugin/`)
- Plugin-facing skill bundle (`skills/`)
- Full documentation suite (docs/)
- MIT license
