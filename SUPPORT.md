# Support

## Getting Help

- **Documentation**: Start with the [docs/](docs/) directory for installation, adoption, and usage guides.
- **FAQ**: Check [docs/faq.md](docs/faq.md) for common questions and troubleshooting.
- **Issues**: Open a [GitHub Issue](../../issues) for bugs, feature requests, or questions.

## Reporting Bugs

When reporting a bug, include:

- What you were trying to do
- What happened instead
- Your OS, shell, and Node.js version
- The output of `ui-architect-skill status` (if applicable)
- Steps to reproduce

## Feature Requests

Open a GitHub Issue with the label `enhancement`. Describe the use case and why the current behavior is insufficient.

## Contributing

See [CONTRIBUTING.md](CONTRIBUTING.md) for guidelines on submitting changes, adding styles, and the development workflow.
