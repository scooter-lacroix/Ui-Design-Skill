# Retro / 90s Nostalgia — Token Card

## Identity
- **Mood**: Nostalgic, chaotic, unapologetically loud
- **Best For**: Novelty/fun products, retro-themed events, personal sites, indie games, nostalgia marketing
- **Avoid For**: Professional services, healthcare, finance, accessibility-critical apps, luxury brands

## Color Tokens
| Token | Value | Usage |
|:------|:------|:------|
| Background | `#C0C0C0` | Windows 95 button face gray |
| Foreground | `#000000` | Pure black text |
| Accent | `#0000FF` | Hyperlinks (unvisited) — pure blue |
| Secondary | `#FF0000` | Hot red emphasis |
| Tertiary | `#FFFF00` | Bright yellow highlights/badges |
| Success | `#00FF00` | Lime green (hit counters, stats) |
| Title Bar | `#000080` → `#1084D0` | Windows title bar navy gradient |

## Typography
- **Heading Font**: Arial Black / Impact
- **Body Font**: MS Sans Serif / Tahoma / Verdana
- **Key Weights**: Bold and Black only — no thin fonts
- **Display Scale**: text-6xl (96px), always UPPERCASE

## Geometry
- **Border Radius**: 0px EVERYWHERE — no exceptions (border-radius didn't exist)
- **Border Style**: 2px with 4-value bevel pattern (`#fff #808080 #808080 #fff` for outset)
- **Shadow System**: Inset box-shadows for 3D bevel effects only; no soft drop shadows

## Motion
- **Easing**: linear or instant (no smooth easing)
- **Speed**: 0-75ms (instant or near-instant state changes)
- **Signature Motion**: Rainbow text cycling (4s linear infinite); pulse-glow badges; marquee scrolling text

## Signature Elements (Bold Factor)
- 3D beveled everything (outset/inset border-color + inset box-shadow)
- Windows 95 title bar cards (navy gradient header, inset content area)
- Marquee scrolling text with colorful spans
- Animated rainbow text on hero headlines
- Construction stripe backgrounds (yellow/black 45° repeating gradient)
- Hit counter aesthetic (green monospace on black, beveled frame)

## Anti-Patterns
- Any border-radius (not even 1px)
- Soft drop shadows or gradients (except title bar/stripes)
- Semi-transparent overlays
- Thin or light font weights
- Smooth easing transitions
- Modern minimalist spacing (must be dense)

## Blend Compatibility
- **Family**: retro
- **Blends Well With**: terminal, playful geometric, neo-brutalism
- **Conflicts With**: luxury, organic-natural, neumorphism
