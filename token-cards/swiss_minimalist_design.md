# Swiss International (Typographic Style) — Token Card

## Identity
- **Mood**: Intellectual, architectural, precise
- **Best For**: Museums, architecture firms, design portfolios, academic publications, transit systems
- **Avoid For**: Playful apps, children's products, casual brands, lifestyle/wellness

## Color Tokens
| Token | Value | Usage |
|:------|:------|:------|
| Background | `#FFFFFF` | Pure white canvas |
| Foreground | `#000000` | Pure black text — absolute |
| Muted | `#F2F2F2` | Light gray secondary backgrounds |
| Accent | `#FF3000` | Swiss Red — the ONLY signal color, used sparingly |
| Border | `#000000` | Pure black — structure is visible |

## Typography
- **Heading Font**: Inter (closest to Helvetica/Akzidenz-Grotesk)
- **Body Font**: Inter
- **Key Weights**: 400, 500, 700, 900 (Black for headlines)
- **Display Scale**: text-9xl to text-[10rem] — headlines as images

## Geometry
- **Border Radius**: 0px strictly rectangular — no rounded corners
- **Border Style**: Thick visible borders (border-2 to border-4); defines the grid
- **Shadow System**: No drop shadows — flatness maintained; only subtle ring shadows for geometric compositions

## Motion
- **Easing**: ease-out / ease-linear (duration-150 to duration-200)
- **Speed**: 150-200ms (instant, mechanical, snappy)
- **Signature Motion**: Full color inversions on hover (not fades); rotating plus icons (0°→90°); vertical slide text replacement in nav

## Signature Elements (Bold Factor)
- Massive responsive typography scaling to text-[10rem]
- Visible grid structure via 4px black borders and asymmetric column ratios
- Numbered section labels in red ("01. System", "02. Method")
- Layered geometric compositions (Bauhaus-inspired circles, rectangles, lines)
- Four CSS texture patterns (grid 24px, dot matrix 16px, diagonal, noise)
- UPPERCASE headings with extreme tracking contrast

## Anti-Patterns
- Rounded corners of any kind
- Drop shadows or 3D depth effects
- Gradients (especially soft color gradients)
- Centered text alignment (must be flush-left, ragged-right)
- Decorative ornamentation unrelated to content
- Subtle opacity fades on hover (use bold color inversions)

## Blend Compatibility
- **Family**: flat
- **Blends Well With**: newsprint, monochrome, bauhaus
- **Conflicts With**: neumorphism, organic-natural, vaporwave
