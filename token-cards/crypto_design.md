# Crypto Design — Token Card

## Identity
- **Mood**: Secure, Technical, Valuable
- **Best For**: DeFi platforms, crypto exchanges, blockchain dashboards, financial technology products, NFT marketplaces
- **Avoid For**: Children's products, healthcare/wellness, traditional editorial content, warm/lifestyle brands

## Color Tokens
| Token | Value | Usage |
|:------|:------|:------|
| Background | `#030304` (True Void) | Deepest page background |
| Surface | `#0F1115` (Dark Matter) | Cards, panels, elevated surfaces |
| Primary Accent | `#F7931A` (Bitcoin Orange) | CTAs, links, active states, trust indicators |
| Secondary Accent | `#EA580C` (Burnt Orange) | Gradients, secondary elements, depth |
| Tertiary Accent | `#FFD600` (Digital Gold) | Highlights, success states, value indicators |
| Muted | `#94A3B8` (Stardust) | Secondary text, descriptions, metadata |
| Border | `#1E293B` (Dim Boundary) | Subtle borders at rest, 10-20% opacity |

## Typography
- **Heading Font**: Space Grotesk (geometric grotesque)
- **Body Font**: Inter (screen-optimized sans-serif)
- **Key Weights**: 400 (Regular), 500 (Medium), 600 (Semibold), 700 (Bold)
- **Display Scale**: `text-4xl` to `md:text-7xl` (dramatic display-to-body contrast)

## Geometry
- **Border Radius**: Cards `rounded-2xl` (16px), Buttons `rounded-full` (pill), Inputs `rounded-lg` (8px)
- **Border Style**: Ultra-thin 1px borders (`border-white/10` at rest, orange on hover/focus)
- **Shadow System**: Colored luminescence — orange/gold tinted glows replace all black shadows

## Motion
- **Easing**: ease-in-out (custom float), linear (orbital spins)
- **Speed**: 200ms (input focus), 300ms (card/button transitions), 8-15s (ambient animations)
- **Signature Motion**: Floating 3D orbital rings with spinning animation, pulsing live-status badges

## Signature Elements (Bold Factor)
- Gradient text on final 1-2 words of hero headlines (`#F7931A` to `#FFD600` with bg-clip-text)
- Spinning orbital rings in hero section (dual counter-rotating CSS animations)
- Corner border accents on "How It Works" cards (decorative orange corner segments)
- Glass morphism panels with backdrop-blur layered over grid patterns
- Timeline-as-blockchain vertical layout with numbered circular nodes on gradient line
- Colored shadows everywhere — no pure black shadows exist in this system

## Anti-Patterns
- Generic dark mode with flat black backgrounds and white-only accents
- Rounded rectangle cards without glow or glass effects
- Black or gray drop shadows on any element
- Light mode or pastel color schemes
- Skeuomorphic or realistic textures (wood, paper, fabric)
- Minimalist whitespace-heavy layouts without luminescent depth

## Blend Compatibility
- **Family**: industrial
- **Blends Well With**: Terminal, Modern Dark, Neuromorphic
- **Conflicts With**: Flat, Organic-Natural, Playful Geometric
